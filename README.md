# SSU Project

A comprehensive school management system built with Flutter (frontend) and Dart (backend server).

## Features

- Student enrollment and management
- Staff management
- Parent communication
- Fee collection and management
- Curriculum management
- Exam and grading system
- Report card generation
- Offline-first architecture
- Real-time communication

## Project Structure

- `test/` - Flutter mobile/web application
- `school_server/` - Dart backend server
- `syllabus_data_structure/` - Curriculum data
- `cleaned_syllabi/` - Processed syllabus documents

## Development Setup

See `README.dev.md` for detailed development instructions.

## Getting Started

1. Clone the repository
2. Follow the setup instructions in `README.dev.md`
3. Run the backend server
4. Run the Flutter app
